| File | Nội dung |

Gợi ý chụp ảnh:

1. Mở trang tương ứng trên trình duyệt.
2. Chụp toàn bộ cửa sổ để thấy rõ URL và trạng thái.
3. Lưu ảnh đúng định dạng `.png` và đúng tên ở bảng trên.
